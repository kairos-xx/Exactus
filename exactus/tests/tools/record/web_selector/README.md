# `web_selector/`

Standalone web page used by the selector tests: the harness serves it through
[`selector_support.py`](../selector_support.py) and every element declares its
geometry through `data-*` attributes.

<!-- exactus:inventory:start -->
## Directory contents

### Files

- [`code.js`](code.js) — Position every element that declares its box through data attributes.
- [`index.html`](index.html) — Provide index html content.
- [`style.css`](style.css) — Provide style css content.

No subdirectories.
