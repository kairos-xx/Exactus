# `project/`

Tiny watched-source fixture for the `run.py` example: running the example
watches this tree and continuously copies it to
`../results/project-watch-copy` and `../results/project-mirror`. Edit any
file here while the example runs to see both destinations update — deleting
a file removes it only from `project-mirror`.
