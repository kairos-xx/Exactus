# Foundation

Document reset, page and typographic foundation.

`semantic.css` holds the component's contextual aliases; `style.css` holds its rules and is imported in cascade order from `../../style.css`.

## Directory contents

### Files

- [`semantic.css`](semantic.css) — Contextual aliases of the foundation component. Each alias selects exactly one CATALOG specification for one declaration.
- [`style.css`](style.css) — Document reset, page and typographic foundation.

### Subdirectories

No subdirectories.
