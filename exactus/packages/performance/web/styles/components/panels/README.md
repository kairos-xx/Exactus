# Panels

Panel surfaces, headings, legend dots and canvases.

`semantic.css` holds the component's contextual aliases; `style.css` holds its rules and is imported in cascade order from `../../style.css`.

## Directory contents

### Files

- [`semantic.css`](semantic.css) — Contextual aliases of the panels component. Each alias selects exactly one CATALOG specification for one declaration.
- [`style.css`](style.css) — Panel surfaces, headings, legend dots and canvases.

No subdirectories.
