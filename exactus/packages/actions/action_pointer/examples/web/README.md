# `web/`

Browser assets for the pointer-action example.

- `index.html` provides the accessible demo workspace and live targets.
- `code.js` mounts `PointerStudio`, previews the form document, and records target interactions.
- `demo.css` supplies the standalone visual token hierarchy and responsive layout.
