# `examples/`

Runnable browser demonstration of the shared pointer and touch action frontend.

Run it with:

```sh
python -m exactus.packages.actions.action_pointer.examples
```

The demo switches through all eleven operations, shows the submitted form document, and includes live targets for click, hover, drag, scroll, and touch-oriented configurations.
