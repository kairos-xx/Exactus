# `web/`

Contain web resources and their directory inventory.

`dashboard.html`, `dashboard.css` and `dashboard.js` are the readable
dashboard assets; `render_html` in `../core.py` embeds them into the
generated TODO dashboard as data URLs so the output remains a single
offline file. `dashboard.d.ts` documents the script's DOM contract.

<!-- exactus:inventory:start -->
## Directory contents

### Files

- [`dashboard.css`](dashboard.css) — Provide dashboard css content.
- [`dashboard.d.ts`](dashboard.d.ts) — Provide dashboard.d ts content.
- [`dashboard.html`](dashboard.html) — Provide dashboard html content.
- [`dashboard.js`](dashboard.js) — Find a dashboard control by its stable DOM identifier.

### Subdirectories

No subdirectories.
