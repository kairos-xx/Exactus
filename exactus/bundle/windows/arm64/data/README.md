# `data/`

Bundle metadata, measurements, and partitioned payloads.

Generated by the offline bundle builder. Keep these assets with the package; normal runs preserve existing packs and catalogs.

## Directory contents

### Files

- [`bundle.json`](bundle.json) — Provide bundle json content.
- [`metrics.json`](metrics.json) — Provide metrics json content.

### Subdirectories

- [`parts/`](parts/README.md) — Run this package with `python -m exactus.bundle.windows.arm64` or `python exactus/bundle/windows/arm64`. Keep __init__.py, __main__.py, partition_fs.py, partition_launcher.py, conflict_copies.py, zstd_portable/, and data/ together. JSON metadata is in data/bundle.json and data/metrics.json; the catalog and packs are in data/parts/fs/. Runtime is offline.
