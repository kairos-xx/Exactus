# `action_rest/`

Reusable browser request-studio controller with a standalone browser demo. `request_studio.js` contains the `RequestStudio` class and `index.js` is the named/default ES-module entry point. The package supports HTTP and WebSocket request workflows, variables, query parameters, headers, cookies, body editing, response inspection, and response-value capture.
