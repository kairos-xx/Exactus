# `action_javascript/`

Reusable, self-rendering **JavaScript snippet runner**: write a snippet, run it in a sandbox, and read what it **returned**, what it **logged**, and **where it failed** — without leaving the action form. It embeds `widget_console` for output and shares its visual language.
