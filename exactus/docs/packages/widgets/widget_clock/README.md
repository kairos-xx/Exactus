## Directory contents

### Files

- [`DOCS.md`](DOCS.md) — `exactus.packages.widgets.widget_clock` is a reusable browser widget package. `widget_clock.js` defines the `AnalogClock` class (seven-segment and dot-matrix rendering modes) and installs one shared `.sst-*` stylesheet automatically via `adoptedStyleSheets` — no external widget CSS is needed. `index.js` is the named/default ES-module facade; the plain script also supports being loaded as a classic script so the demo works when opened as a local file. Methods use arrow class fields; pure helpers are static.
