# `widget_console/`

Reusable, self-rendering **console widget**: a filterable, searchable message list that shows values the way a developer console does — expandable objects, maps, sets, errors with stacks, `console.table`, groups, repeat counters, and per-level tinting — in the same visual language as `extended_selector` and `action_rest`.
