# `performance/`

`exactus.packages.performance` turns timestamped `exactus.packages.steps` traces into an immutable performance model and an interactive browser profiler. It is designed for Exactus result trees but also accepts individual `steps.txt` files.

<!-- exactus:inventory:start -->
## Directory contents

### Files

- [`DOCS.md`](DOCS.md) — `exactus.packages.performance` turns timestamped `exactus.packages.steps` traces into an immutable performance model and an interactive browser profiler. It is project-agnostic: it accepts any mix of `steps.txt` files, directories, or glob expressions, and the `exactus` tool layer (`exactus/tools/performance`) supplies the Exactus-specific `EXACTUS_RESULTS` scan root and report destination.

### Subdirectories

No subdirectories.
