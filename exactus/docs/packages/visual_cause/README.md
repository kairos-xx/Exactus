## Directory contents

### Files

- [`DOCS.md`](DOCS.md) — `exactus.packages.visual_cause` renders one page under two CSS targets (or two whole pages), performs counterfactual browser interventions — removing or restoring individual rules, declarations and value subexpressions — and reports which CSS actually *caused* each visual difference, with pixel evidence. It runs on Playwright/Chromium and Pillow.
