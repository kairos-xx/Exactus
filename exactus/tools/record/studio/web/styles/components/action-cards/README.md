# Action cards

The Shortcuts-style card of an action: a coloured icon tile, one sentence with editable tokens and variable pills, a code block, If / End If branch cards and the small editor a token opens.

`semantic.css` holds the component's contextual aliases; `style.css` holds its rules and is imported in cascade order from `../../style.css`.

<!-- exactus:inventory:start -->
## Directory contents

### Files

- [`semantic.css`](semantic.css) — Contextual aliases of the action cards component. Each alias selects exactly one CATALOG specification for one declaration.
- [`style.css`](style.css) — Action cards: the coloured tile, the sentence with its tokens and pills, the code block, branch cards and the small editor a token opens.

### Subdirectories

No subdirectories.
