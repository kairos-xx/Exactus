# Request actions

The compact REST and WebSocket request composer used by Studio action forms. It
adapts REST action's request line and tabs to Studio's action-card shell and
adds variable mentions, response checks, and typed response-to-variable maps.

`semantic.css` selects generic catalog specifications for this component;
`style.css` contains only terminal component rules.
