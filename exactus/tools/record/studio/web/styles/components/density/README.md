# Density

Aliases and rules of the density component.

`semantic.css` holds the component's contextual aliases; the `style*.css` files hold its rules and are imported in cascade order from `../../style.css`.

Original sources: `24-density`.

## Directory contents

### Files

- [`semantic.css`](semantic.css) — Contextual aliases of the density component. Each alias selects exactly one CATALOG specification for one declaration.
- [`style.css`](style.css) — Rules of the density component.
