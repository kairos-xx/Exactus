# Flow inputs

The inputs a flow takes: one bordered row per input (name, type, required, default) in the flow settings.

`semantic.css` holds the component's contextual aliases; `style.css` holds its rules and is imported in cascade order from `../../style.css`.

<!-- exactus:inventory:start -->
## Directory contents

### Files

- [`semantic.css`](semantic.css) — Contextual aliases of the flow inputs component. Each alias selects exactly one CATALOG specification for one declaration.
- [`style.css`](style.css) — The list of inputs a flow takes, edited in the flow settings.

### Subdirectories

No subdirectories.
