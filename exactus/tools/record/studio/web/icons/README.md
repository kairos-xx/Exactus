# Flow Studio icons

Owned SVGs from [Tabler Icons](https://tabler.io/icons), outline variant.
Better Design resolved the names and supplied the initial files. Additional
verified names came from the same official Tabler repository after Iconify
rate-limited downloads. The original license is included in `LICENSE`.

The editor renders these assets through CSS masks using current text color.
No CDN, icon font or runtime network request is required. Glyphs are decorative;
buttons retain visible labels or accessible names. `.library.json` records the
locked family. Keep SVGs, stylesheet mappings and package-data entries together.
