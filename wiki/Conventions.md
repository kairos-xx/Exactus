# Conventions

The rules below are enforced by the gate — code that violates them does
not merge. The canonical policy is [AGENTS.md](../AGENTS.md).

## Validation

- **Bare `exactus` is the single gate.** Do not substitute separate
  ruff / basedpyright / format runs for it; they are components, not
  the gate. Report PASS / FAIL / NOT RUN honestly — a timeout or crash
  is not a pass.
- Warnings are actionable: `unresolved-callee`, docstring and style
  warnings all block. Never add `noqa`, `type: ignore` or exclusions to
  silence a finding; fix the root cause.

## Python style

- **Docstrings** — Google style on every module, class and public
  member; the `docs` tool requires `Args:`/`Returns:` sections matching
  the signature (including `*`-only parameters).
- **Imports** — `from x import name` only. Bare `import x` used purely
  through attributes is flagged (PY001); `pytest`/`sys` are the
  configured exceptions.
- **Constants** — module-level constants live in a `class Constants`
  grouping with `Final` annotations.
- **Signatures** — keyword-only APIs use `*,`; exceptions assign
  `msg: str = ...` before `raise`; writes use `_ = path.write_text(...)`
  / `_ = stdout.write(...)`.
- **Dataclasses** — `@dataclass(frozen=True, slots=True)` for value
  types; document `Attributes:` in the class docstring.
- **Line length** — 79 columns; long strings are joined literals or
  `dedent` blocks, never `noqa`'d E501.

## JavaScript

ES modules with JSDoc `/** @typedef */`/`@param` documentation; tabs;
`const`/`Object.freeze` defaults; custom CSS-token, delimiter and
function-block rules run inside the lints tool.

## Layout rules

- `exactus/docs/<leaf>/DOCS.md` documents `exactus/<leaf>/` — keep the
  bespoke prose, regenerate the `exactus:reference` tail with
  `dev/generate_docs_reference.py`.
- `wiki/` is generated by `dev/generate_wiki.py` — leaf pages are
  regenerated, guide pages are hand-written.
- `tests/` mirrors `packages/` and `tools/` one-for-one; every package
  keeps runnable `examples/` and a `README.md`.
- Generated artifacts (`EXACTUS_RESULTS/`, `.scratch/`, `build/`,
  `bin/release/`, `.build-cache`) are outputs — restore them to HEAD
  before committing source changes.

## Git

Conventional-style messages focused on *why*; never weaken rules,
thresholds or exclusions to obtain green. `main` is the release branch
— keep it clean and pushed.
